门锁

这间屋子，只住两个人

Love小家处理的是情侣之间的照片、视频、消息和位置，所以安全边界不是附加功能，而是核心设计。

情侣空间隔离

每个用户只属于一个情侣空间，业务查询以 couple_id 为边界；Supabase Postgres 用 RLS 限制空间之外的访问，22 张数据表全部覆盖。

私密媒体签名地址

照片、视频、语音走 Storage 签名地址，不把公开永久文件 URL 作为主要访问方式；浏览器缓存与分批加载只为减少等待，不为绕开权限。

密钥不出前端

前端只用 Supabase anon key；service role key、ZEGO ServerSecret、AI Key 只允许放在服务端，浏览器里找不到它们。

服务端代理与限流

AI 请求、ZEGO Token、账户操作全部走 Supabase Edge Functions；AI 侧有请求长度限制、频率限制与错误提示，不把生成变成不可控的黑盒。

问答

常见问题

点开看答案，不点也能往下翻。

不配置 ZEGO、地图这些外部服务，能用吗？

能。通话、系统通知、实时位置和地图需要浏览器或系统权限以及对应的 Supabase、ZEGO 或地图服务配置；未配置外部服务时，核心页面仍可启动并用于本地演示。

我的照片和聊天会被公开吗？

不会。每个用户只属于一个情侣空间，业务查询以 couple_id 为边界，Postgres RLS 限制空间之外的访问；媒体走 Storage 签名地址，不用公开永久文件 URL。

一定要部署自己的后端吗？

不一定。可以直接用在线演示 love-home.pages.dev；想把数据完全放在自己手里，再按仓库文档自托管一套。

AI 功能用的是什么模型？密钥安全吗？

小米 MiMo，约会策划、共同日记与情书生成。请求经 Supabase Edge Function 代理，API Key 不放进前端；服务端有请求长度限制与频率限制。

收费吗？

项目本身 MIT 开源。自托管只涉及你自己的服务资源（Supabase、ZEGO、地图等按需接入的服务），没有来自项目本身的订阅费。

通话失败报 1102016 是什么意思？

ZEGO Token 无效或已过期的一种：Edge Function 使用的 AppID 与网页配置不一致。请确认两边 AppID 相同，并重新部署 Token Function。
