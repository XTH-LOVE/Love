✦ 快速上手

三步开启你们的空间

开源、可自托管。克隆仓库，配置好环境变量，几分钟就能拥有属于自己的情侣空间。

1

克隆 & 安装

git clone 仓库后运行 npm install，复制 .env.example 为 .env 并填入 Supabase 配置。

2

初始化数据库

使用 Supabase CLI 推送 migrations，部署 Edge Functions 并配置 AI 和通话密钥。

3

启动 & 部署

npm run dev 本地预览，npm run generate 生成静态站点，部署到 Cloudflare Pages。

✦ 安全与隐私

安全边界是核心设计

Love小家处理的是情侣之间的私密数据。安全不是事后补丁，而是从第一行代码就开始的坚持。

隐私优先架构

每一层数据访问都经过严格隔离。从数据库行级安全到 AI 密钥管理，全链路保护你们的私密数据。

🔒RLS 行级安全策略，数据以 couple_id 为边界隔离
🔑Storage 签名地址，不暴露公开永久文件 URL
🛡️敏感密钥只存服务端 Edge Function Secrets
🌐AI 请求通过服务端转发，浏览器不接触供应商密钥

✦ 常见问题

你可能想知道的

关于部署、使用和安全的一些常见问题解答。

登录后为什么还是演示模式？▾

检查 .env 中的 Supabase URL 和 anon key，确认部署环境也配置了相同变量，并重新生成静态文件。

通话提示 Token 无效怎么办？▾

ZEGO 的前端 App ID 不能替代 ServerSecret。请在 Supabase Edge Function Secrets 中配置真实密钥。

能不能只用网页，不构建 APK？▾

当然可以。运行 npm run generate 后部署 .output/public/ 到静态托管即可。

数据存储在哪里？是否安全？▾

所有数据存储在你自己配置的 Supabase 项目中，使用 RLS 行级安全策略隔离，可完全自托管。

如何贡献代码或提出建议？▾

欢迎在 GitHub 提交 Issue 或 Pull Request。Fork 仓库，创建功能分支，保持修改范围清晰即可。
